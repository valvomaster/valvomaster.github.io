สอบ ก.พ.

นโยบายความเป็นส่วนตัว

ปรับปรุงล่าสุด: 5 กันยายน 2569

1. ภาพรวม

แอพ "สอบ ก.พ." เป็นแอพทดลองทำข้อสอบแบบ offline-first ไม่มีระบบสมาชิก ไม่มี server เพื่อเก็บข้อมูลผู้ใช้ ข้อมูลเกือบทั้งหมดที่เกี่ยวกับตัวคุณจึงถูกเก็บไว้ในเครื่องของคุณเองเท่านั้น นโยบายนี้อธิบายว่าเรา (และผู้ให้บริการโฆษณาที่เราใช้) เก็บอะไรบ้าง

แอพนี้เป็นเครื่องมือฝึกฝนอิสระ ไม่ใช่ข้อสอบทางการ และไม่มีส่วนเกี่ยวข้องกับสำนักงาน ก.พ. ดูรายละเอียดข้อจำกัดความรับผิดชอบฉบับเต็มได้ที่หน้า "เงื่อนไขการใช้งาน" ในแอพ

2. ข้อมูลที่เก็บในเครื่องคุณเท่านั้น

  • ชื่อเล่น - ตั้งได้อิสระ ไม่ใช่ชื่อจริง ไม่ผูกกับตัวตนหรือบัญชีใด ๆ
  • รูปโปรไฟล์ - ถ้าคุณเลือกอัพโหลดรูปจากเครื่อง แอพจะคัดลอกไฟล์นั้นเก็บไว้ในพื้นที่เก็บข้อมูลของแอพในเครื่องคุณเท่านั้น เราไม่มี server ให้ส่งรูปไปเก็บ จึงไม่มีการอัพโหลดขึ้นที่ใดทั้งสิ้น
  • ประวัติการทำข้อสอบและคะแนน (ทุกโหมด ทั้งสอบเต็มชุด/ฝึกเฉพาะหมวด/ทบทวนข้อผิด) - เก็บในเครื่องเพื่อให้คุณดูสถิติย้อนหลังและใช้คำนวณ "จุดผิดพลาดที่ควรทบทวน" ให้เอง ทั้งหมดประมวลผลในเครื่องคุณ ไม่มีการส่งข้อมูลคำตอบหรือคะแนนออกไปนอกเครื่องเลย
  • ข้อที่คุณปักธงไว้ว่า "ไม่แน่ใจ" ระหว่างทำข้อสอบ
  • วันที่คุณตั้งไว้ว่าเป็นวันสอบจริง (ถ้าตั้งค่าไว้) ใช้แสดงตัวนับถอยหลังในหน้าแรกเท่านั้น
  • จำนวนวันที่เปิดแอพติดต่อกัน (streak)

ข้อมูลทั้งหมดในหัวข้อนี้จะหายไปทันทีถ้าคุณลบแอพ หรือกดปุ่ม "ลบข้อมูลส่วนตัวทั้งหมด" ในแอพ (ตั้งค่า → นโยบายความเป็นส่วนตัว)

3. ข้อมูลจากผู้ให้บริการโฆษณา (AdMob)

แอพนี้ใช้ Google AdMob เพื่อแสดงโฆษณาสำหรับผู้ใช้ที่ยังไม่ได้ปลดล็อค ตัว AdMob SDK อาจเก็บและส่งข้อมูลต่อไปนี้ออกจากเครื่องคุณเพื่อเลือกโฆษณาที่เกี่ยวข้อง:

  • Advertising ID ของอุปกรณ์ (Android AAID / iOS IDFA)
  • ข้อมูลทางเทคนิคของอุปกรณ์ เช่น รุ่นเครื่อง, ระบบปฏิบัติการ, ที่อยู่ IP โดยประมาณ
  • ปฏิสัมพันธ์กับโฆษณา เช่น การดู/การคลิก

บน iOS แอพจะขอสิทธิ์ App Tracking Transparency (ATT) ก่อนใช้ข้อมูลนี้เพื่อยิงโฆษณาแบบเจาะจงเสมอ คุณสามารถปฏิเสธได้ แอพจะยังใช้งานได้ปกติ เพียงแต่โฆษณาที่เห็นจะไม่ถูกปรับให้ตรงความสนใจเท่านั้น ดูรายละเอียดเพิ่มเติมได้ที่นโยบายความเป็นส่วนตัวของ Google

ถ้าคุณปลดล็อคผ่านการซื้อในแอพแล้ว โฆษณาทั้งหมดจะถูกปิด และ AdMob SDK จะไม่ถูกเรียกใช้งานอีก

4. ข้อมูลจากผู้ให้บริการชำระเงิน

การซื้อสินค้าในแอพดำเนินการผ่านระบบของ Google Play หรือ App Store โดยตรง เราไม่เห็นและไม่เก็บข้อมูลบัตรเครดิตหรือข้อมูลการชำระเงินใด ๆ ของคุณเลย ธุรกรรมทั้งหมดอยู่ในความรับผิดชอบของ Apple/Google ตามนโยบายความเป็นส่วนตัวของแต่ละแพลตฟอร์ม

5. เราไม่ทำอะไรกับข้อมูลคุณบ้าง

  • ไม่มีการขายหรือให้เช่าข้อมูลส่วนตัวแก่บุคคลที่สาม
  • ไม่มีระบบ analytics ติดตามพฤติกรรมนอกเหนือจากสถิติพื้นฐานที่ AdMob SDK เก็บเพื่อจุดประสงค์ด้านโฆษณาเท่านั้น
  • ไม่มีการเชื่อมข้อมูลในแอพนี้กับบัญชี social media หรือแอพอื่นของคุณ

6. สิทธิ์ของคุณ

เนื่องจากข้อมูลส่วนตัวเก็บในเครื่องคุณเองทั้งหมด คุณจึงมีสิทธิ์เต็มที่ในการลบข้อมูลได้ทันทีด้วยตัวเอง ผ่านปุ่ม "ลบข้อมูลส่วนตัวทั้งหมด" ในแอพ (ตั้งค่า → นโยบายความเป็นส่วนตัว) หรือการลบแอพออกจากเครื่องก็มีผลเทียบเท่ากัน

7. เด็กและเยาวชน

แอพนี้ไม่ได้จัดทำขึ้นเพื่อเจาะจงกลุ่มเด็กอายุต่ำกว่า 13 ปี เนื้อหาเป็นข้อสอบเตรียมสอบทั่วไป หากคุณเป็นผู้ปกครองและพบว่าบุตรหลานใช้แอพนี้และมีข้อกังวลเรื่องข้อมูล สามารถลบข้อมูลได้ทันทีตามหัวข้อ 6

8. การเปลี่ยนแปลงนโยบาย

เราอาจปรับปรุงนโยบายนี้เป็นครั้งคราวเพื่อให้ตรงกับฟีเจอร์ใหม่หรือข้อกำหนดของ store การเปลี่ยนแปลงจะแสดงวันที่ปรับปรุงล่าสุดไว้ด้านบนของหน้านี้เสมอ
