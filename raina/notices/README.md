# RaiNa notice board pictures

The game shows `1.png`, `2.png`, ... `10.png` (or `.jpg`) as a slideshow when the app opens (once a day) and from the Settings
menu. It stops at the first missing number, so to show 3 pictures keep `1.png`-`3.png` only.

## Per language
- This folder = the shared set (English, worldwide).
- A sub-folder named after a game language is used first for players in that language, e.g. `th/1.png …` for Thai.
  Codes: `en th ja ko zh-Hans zh-Hant es pt-BR fr de it ru tr id vi`.
- A language without its own folder (or with an empty one) gets the shared pictures here.

## Pictures
- Size: 1600 x 900 (16:9, landscape). JPG (quality ~88, ~400 KB) loads faster on phones than a 2.5 MB PNG.
- Replace a picture: overwrite the file with the same name and push. Players see it the next day (or after
  reopening the app). GitHub Pages may take a few minutes to update.
