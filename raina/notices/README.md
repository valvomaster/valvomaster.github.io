# RaiNa notice board pictures

The game shows `1.png`, `2.png`, ... `5.png` from this folder as a slideshow when the app opens (once a day) and
from the Settings menu. It stops at the first missing number, so to show 3 pictures keep `1.png`-`3.png` only.

- Size: 1600 x 900 (16:9, landscape). PNG (or JPG named `1.jpg` …).
- Replace a picture: overwrite the file with the same name and push. Players see it the next day (or after
  reopening the board), GitHub Pages may take a few minutes to update.
